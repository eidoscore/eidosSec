1. Technical Stack Overview
1.1 Technology Selection Rationale
Frontend Stack:
React 18.2+ with TypeScript
 Build Tool: Vite 5.0+
 UI Framework: TailwindCSS 3.4+
 Component Library: shadcn/ui (Radix UI primitives)
 State Management: Zustand 4.5+
 Data Fetching: TanStack Query 5.0+
 Routing: React Router 6.20+
 Forms: React Hook Form 7.50+
 Charts: Recharts 2.10+
 Code Display: Prism.js / Monaco Editor
 WebSocket: socket.io-client 4.7+
 HTTP Client: Axios 1.6+
Why These Choices:

React + TypeScript: Industry standard, large ecosystem, type safety
Vite: Fast dev server, optimized builds (vs. Create React App)
TailwindCSS: Utility-first, no CSS files to manage, consistent design
shadcn/ui: Unstyled primitives, full customization, accessible by default
Zustand: Simpler than Redux, better DX, smaller bundle
TanStack Query: Built-in caching, automatic refetching, optimistic updates
React Router: Standard routing solution, v6 has excellent data loading
React Hook Form: Performant, minimal re-renders, great validation
Recharts: React-native charts, responsive, good docs
Monaco Editor: VS Code editor in browser (for code viewing/editing)
socket.io: Reliable WebSocket with fallbacks (long-polling if WS fails)


Backend Stack:
Python 3.11+ with FastAPI
 Web Framework: FastAPI 0.109+
 ASGI Server: Uvicorn 0.27+
 ORM: SQLAlchemy 2.0+
 Database Driver: asyncpg (PostgreSQL)
 Migration Tool: Alembic 1.13+
 Task Queue: Celery 5.3+ (with Redis backend)
 WebSocket: python-socketio 5.11+
 Validation: Pydantic 2.5+
 Authentication: python-jose (JWT)
 Password Hashing: passlib (bcrypt)
 HTTP Client: httpx 0.26+
 PDF Generation: WeasyPrint 60+
 Testing: pytest 8.0+
Why These Choices:

Python: Ecosystem for security tools, easy integration, readable
FastAPI: Fast, async support, auto-generated OpenAPI docs, type hints
Uvicorn: High-performance ASGI server, production-ready
SQLAlchemy 2.0: Mature ORM, async support, prevents SQL injection
asyncpg: Fastest PostgreSQL driver, async/await support
Alembic: Standard migration tool for SQLAlchemy
Celery: Battle-tested task queue, good for long-running scans
python-socketio: Compatible with socket.io client, easy integration
Pydantic: Data validation, serialization, integrates with FastAPI
python-jose: JWT implementation for API authentication
passlib: Industry-standard password hashing (bcrypt)
httpx: Async HTTP client (for external API calls like LLM)
WeasyPrint: HTML/CSS to PDF conversion
pytest: Most popular Python testing framework


Scanner Worker Stack:
Python 3.11+ Orchestrator
 Tool Execution: subprocess (secure command execution)
 Output Parsing: JSON, XML parsers
 AST Analysis: tree-sitter (for deduplication)
 File Handling: pathlib, shutil
 Git Operations: GitPython 3.1+
 Concurrency: asyncio for parallel tool execution
Why These Choices:

Python: Same language as backend, easier maintenance
subprocess: Safe command execution (avoid shell injection)
tree-sitter: Fast, incremental parsing for code similarity detection
GitPython: Pure Python Git implementation, no shell dependencies
asyncio: Run multiple tools in parallel (utilize multi-core)


Database Stack:
PostgreSQL 15+
 Connection Pooling: pgBouncer (optional for high load)
 Full-Text Search: Built-in tsvector (for finding search)
 JSON Storage: JSONB columns (for flexible data like tool outputs)
 Extensions: pg_trgm (fuzzy text search)
Why PostgreSQL:

Open-source, mature, reliable
JSONB for flexible schema (tool outputs vary by tool)
Full-text search built-in
ACID compliance
Excellent performance for read-heavy workloads


Message Queue / Cache:
Redis 7+
 Use Cases:
    Celery task queue backend
    WebSocket pub/sub (scan progress updates)
    Session storage (optional multi-user mode)
    Caching (scan results, tool outputs)
 Persistence: AOF (Append-Only File) enabled
 Eviction: LRU (Least Recently Used) for cache
Why Redis:

In-memory speed for real-time updates
Pub/sub for WebSocket broadcasting
Built-in data structures (lists, sets, sorted sets)
Persistence options for durability


Security Tools (Integrated):
See Section 7 for detailed integration specs. High-level:

SAST: Semgrep, CodeQL, Bandit, Brakeman, PHPStan, ESLint, etc.
DAST: OWASP ZAP, Nuclei, Wapiti, Nikto
SCA: Trivy, Grype, OWASP Dependency-Check, npm audit
Secrets: TruffleHog, Gitleaks, detect-secrets
Container: Trivy, Dockle, Hadolint
IaC: Checkov, Terrascan, tfsec, Kics

All tools installed in Scanner Worker Docker image.

### 2.2 Component Interactions

**Flow 1: User Initiates Scan**
```
1. User clicks "Quick Scan" in Browser
   
   ï¿½
2. Frontend sends POST /api/v1/scans
   {project_id: "abc", mode: "quick"}
   
   ï¿½
3. Backend (FastAPI) receives request
    Validates project exists
    Creates scan record in PostgreSQL (status: "pending")
    Generates scan_id
    Enqueues Celery task to Redis
   
   ï¿½
4. Returns to Frontend immediately
   {scan_id: "xyz", status: "queued"}
   
   ï¿½
5. Frontend establishes WebSocket connection
   ws://localhost:8000/ws/scans/xyz
   
   ï¿½
6. Celery Worker picks up task from Redis queue
    Updates scan status to "running" in PostgreSQL
    Publishes "Scan started" to Redis pub/sub
    Invokes Scanner Worker
   
   ï¿½
7. Scanner Worker executes tools
    Reads project code from /app/projects/abc
    Runs Semgrep, Gitleaks, Trivy, etc.
    Publishes progress updates to Redis pub/sub
      ("15% - Semgrep completed")
    Returns results to Celery Worker
   
   ï¿½
8. Celery Worker processes results
    Deduplication
    Confidence scoring
    Stores findings in PostgreSQL
    Updates scan status to "completed"
    Publishes "Scan completed" to Redis pub/sub
   
   ï¿½
9. Backend broadcasts updates via WebSocket
   
   ï¿½
10. Frontend receives WebSocket message
     Updates progress bar (real-time)
     On completion, fetches results via GET /api/v1/scans/xyz
    
    ï¿½
11. Frontend displays results to user
```

**Key Configuration Notes:**

1. **Network Isolation:** All containers on `eidossec-network`, no bridge mode
2. **Read-Only Mounts:** User code mounted read-only to prevent modifications
3. **Resource Limits:** Scanner limited to 8GB RAM, 4 CPU to prevent system overload
4. **Health Checks:** All services have health checks for monitoring
5. **Restart Policy:** `unless-stopped` ensures containers restart on failure
6. **Volumes:** Named volumes for persistence (database, Redis)
7. **Environment Variables:** Sensitive data via `.env` file (not hardcoded)

3.2 Table Schemas (PostgreSQL DDL)
Table: projects
sqlCREATE TABLE projects (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(255) NOT NULL,
    path TEXT NOT NULL,  -- Absolute path on host system
    languages JSONB DEFAULT '[]'::jsonb,  -- ["php", "javascript"]
    framework VARCHAR(100),  -- "laravel", "django", etc.
    settings JSONB DEFAULT '{}'::jsonb,  -- {scan_mode: "quick", exclude_paths: [...]}
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    
    CONSTRAINT projects_name_unique UNIQUE (name),
    CONSTRAINT projects_path_check CHECK (path ~ '^/.*')  -- Must be absolute path
);

CREATE INDEX idx_projects_name ON projects (name);
CREATE INDEX idx_projects_created_at ON projects (created_at DESC);
Table: scans
sqlCREATE TABLE scans (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id UUID NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    mode VARCHAR(20) NOT NULL CHECK (mode IN ('quick', 'deep', 'custom')),
    status VARCHAR(20) NOT NULL CHECK (status IN ('pending', 'running', 'completed', 'failed', 'cancelled')),
    started_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    completed_at TIMESTAMP WITH TIME ZONE,
    duration_seconds INTEGER,  -- Computed: completed_at - started_at
    score DECIMAL(3,1) CHECK (score >= 0 AND score <= 10),  -- 0.0 to 10.0
    summary JSONB DEFAULT '{}'::jsonb,  -- {critical: 3, high: 8, medium: 15, low: 22}
    tools_executed JSONB DEFAULT '[]'::jsonb,  -- ["semgrep", "gitleaks", ...]
    error_message TEXT,
    
    CONSTRAINT scans_duration_check CHECK (completed_at IS NULL OR completed_at >= started_at)
);

CREATE INDEX idx_scans_project_id ON scans (project_id);
CREATE INDEX idx_scans_status ON scans (status);
CREATE INDEX idx_scans_started_at ON scans (started_at DESC);
CREATE INDEX idx_scans_score ON scans (score);
Table: findings
sqlCREATE TABLE findings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    scan_id UUID NOT NULL REFERENCES scans(id) ON DELETE CASCADE,
    type VARCHAR(100) NOT NULL,  -- "sql_injection", "xss", "hardcoded_secret"
    severity VARCHAR(20) NOT NULL CHECK (severity IN ('critical', 'high', 'medium', 'low', 'info')),
    confidence INTEGER NOT NULL CHECK (confidence >= 0 AND confidence <= 100),
    file_path TEXT NOT NULL,  -- Relative to project root
    line_start INTEGER NOT NULL CHECK (line_start > 0),
    line_end INTEGER NOT NULL CHECK (line_end >= line_start),
    code_snippet TEXT,  -- 10-20 lines of context
    message TEXT NOT NULL,  -- Human-readable description
    cwe_id VARCHAR(20),  -- "CWE-89"
    owasp_category VARCHAR(50),  -- "A03:2021"
    detected_by_tools JSONB NOT NULL DEFAULT '[]'::jsonb,  -- ["semgrep", "codeql"]
    raw_outputs JSONB DEFAULT '{}'::jsonb,  -- {semgrep: {...}, codeql: {...}}
    status VARCHAR(20) DEFAULT 'open' CHECK (status IN ('open', 'fixed', 'false_positive', 'accepted_risk', 'wont_fix')),
    assigned_to VARCHAR(100),  -- Username (optional)
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    
    CONSTRAINT findings_line_range_check CHECK (line_end >= line_start)
);

CREATE INDEX idx_findings_scan_id ON findings (scan_id);
CREATE INDEX idx_findings_severity ON findings (severity);
CREATE INDEX idx_findings_type ON findings (type);
CREATE INDEX idx_findings_status ON findings (status);
CREATE INDEX idx_findings_file_path ON findings (file_path);
CREATE INDEX idx_findings_confidence ON findings (confidence DESC);

-- Full-text search on message and file_path
CREATE INDEX idx_findings_search ON findings USING gin(to_tsvector('english', message || ' ' || file_path));
Table: comments (for collaboration)
sqlCREATE TABLE comments (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    finding_id UUID NOT NULL REFERENCES findings(id) ON DELETE CASCADE,
    user_id UUID REFERENCES users(id) ON DELETE SET NULL,  -- NULL if single-user mode
    comment_text TEXT NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_comments_finding_id ON comments (finding_id);
CREATE INDEX idx_comments_created_at ON comments (created_at DESC);
Table: users (optional, for multi-user mode)
sqlCREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    username VARCHAR(50) NOT NULL UNIQUE,
    email VARCHAR(255) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,  -- bcrypt hash
    role VARCHAR(20) NOT NULL DEFAULT 'developer' CHECK (role IN ('admin', 'security_lead', 'developer', 'viewer')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    last_login_at TIMESTAMP WITH TIME ZONE,
    
    CONSTRAINT users_username_length CHECK (length(username) >= 3),
    CONSTRAINT users_email_format CHECK (email ~ '^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$')
);

CREATE INDEX idx_users_username ON users (username);
CREATE INDEX idx_users_email ON users (email);

@router.websocket("/scans/{scan_id}")
async def websocket_scan_progress(websocket: WebSocket, scan_id: str):
    """
    WebSocket endpoint for real-time scan progress updates.
    Subscribes to Redis pub/sub channel for the scan.
    """
    await websocket.accept()
    
    # Create Redis pub/sub
    pubsub = redis_client.pubsub()
    channel = f"scan:{scan_id}:progress"
    pubsub.subscribe(channel)
    
    try:
        # Listen for messages from Redis and forward to WebSocket
        while True:
            message = pubsub.get_message()
            if message and message['type'] == 'message':
                data = message['data']
                await websocket.send_text(data)
            
            # Small delay to avoid busy-waiting
            await asyncio.sleep(0.1)
            
    except WebSocketDisconnect:
        pubsub.unsubscribe(channel)
        pubsub.close()
    except Exception as e:
        await websocket.close(code=1011, reason=str(e))
        pubsub.unsubscribe(channel)
        pubsub.close()

  addScan: (scan: Scan) => void;
  updateScan: (scanId: string, updates: Partial<Scan>) => void;

  clearProgress: (scanId: string) => void;

export const useScanStore = create<ScanState>((set) => ({
  scans: [],
  currentScan: null,
  scanProgress: {},

  setScans: (scans) => set({ scans }),

  addScan: (scan) =>
    set((state) => ({
      scans: [scan, ...state.scans],
    })),

  updateScan: (scanId, updates) =>
    set((state) => ({
      scans: state.scans.map((s) =>
        s.id === scanId ? { ...s, ...updates } : s
      ),
      currentScan:
        state.currentScan?.id === scanId
          ? { ...state.currentScan, ...updates }
          : state.currentScan,
    })),

  setCurrentScan: (scan) => set({ currentScan: scan }),

  updateProgress: (scanId, progress) =>
    set((state) => ({
      scanProgress: {
        ...state.scanProgress,
        [scanId]: progress,
      },
    })),

  clearProgress: (scanId) =>
    set((state) => {
      const { [scanId]: _, ...rest } = state.scanProgress;
      return { scanProgress: rest };
    }),

hooks/useWebSocket.ts:
typescriptimport { useEffect, useRef, useCallback } from 'react';
import { io, Socket } from 'socket.io-client';
import { ScanProgress } from '@/types';
import { useScanStore } from '@/store/scanStore';

export const useWebSocket = (scanId: string | null) => {
  const socketRef = useRef<Socket | null>(null);
  const { updateProgress, updateScan } = useScanStore();

  const connect = useCallback(() => {
    if (!scanId) return;

    const WS_URL = import.meta.env.VITE_WS_URL || 'ws://localhost:8000';
    
    // Create WebSocket connection
    socketRef.current = io(`${WS_URL}/scans/${scanId}`, {
      transports: ['websocket'],
      reconnection: true,
      reconnectionAttempts: 5,
      reconnectionDelay: 1000,
    });

    // Listen for progress updates
    socketRef.current.on('progress', (data: ScanProgress) => {
      updateProgress(scanId, data);

      // If scan completed, update scan status
      if (data.progress === 100) {
        updateScan(scanId, { status: 'completed' });
      }
    });

    // Listen for errors
    socketRef.current.on('error', (error: any) => {
      console.error('WebSocket error:', error);
      if (error.message) {
        updateProgress(scanId, {
          progress: 0,
          message: `Error: ${error.message}`,
          error: true,
        });
      }
    });

    // Connection established
    socketRef.current.on('connect', () => {
      console.log('WebSocket connected');
    });

    // Connection lost
    socketRef.current.on('disconnect', () => {
      console.log('WebSocket disconnected');
    });

  }, [scanId, updateProgress, updateScan]);

  const disconnect = useCallback(() => {
    if (socketRef.current) {
      socketRef.current.disconnect();
      socketRef.current = null;
    }
  }, []);

  useEffect(() => {
    connect();
    return () => disconnect();
  }, [connect, disconnect]);

  return { isConnected: socketRef.current?.connected || false };
};
hooks/useScans.ts (TanStack Query):
typescriptimport { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
import { scanService } from '@/services/scanService';
import { CreateScanRequest } from '@/types';
import { useScanStore } from '@/store/scanStore';

export const useScans = (projectId?: string) => {
  const queryClient = useQueryClient();
  const { addScan } = useScanStore();

  // Query: List scans
  const scansQuery = useQuery({
    queryKey: ['scans', projectId],
    queryFn: () => scanService.listScans({ project_id: projectId }),
    refetchInterval: 5000,  // Poll every 5s for status updates
  });

  // Mutation: Create scan
  const createScanMutation = useMutation({
    mutationFn: (data: CreateScanRequest) => scanService.createScan(data),
    onSuccess: (newScan) => {
      // Add to local state
      addScan(newScan);
      
      // Invalidate queries to refetch
      queryClient.invalidateQueries({ queryKey: ['scans'] });
    },
  });

  // Mutation: Delete scan
  const deleteScanMutation = useMutation({
    mutationFn: (scanId: string) => scanService.deleteScan(scanId),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['scans'] });
    },
  });

  return {
    scans: scansQuery.data || [],
    isLoading: scansQuery.isLoading,
    error: scansQuery.error,
    createScan: createScanMutation.mutate,
    isCreating: createScanMutation.isPending,
    deleteScan: deleteScanMutation.mutate,
  };
};

export const useScan = (scanId: string | null) => {
  const { data: scan, isLoading, error } = useQuery({
    queryKey: ['scan', scanId],
    queryFn: () => scanService.getScan(scanId!),
    enabled: !!scanId,
    refetchInterval: (data) => {
      // Stop polling when scan is completed/failed
      return data?.status === 'running' ? 2000 : false;
    },
  });

  return { scan, isLoading, error };
};

## 6. Scanner Worker Implementation

### 6.1 Scanner Architecture

The Scanner Worker is the heart of eidosSecit executes 50+ security tools, normalizes outputs, and performs deduplication. It's designed to be modular, extensible, and fault-tolerant.

**Design Principles:**
1. **Tool Isolation:** Each tool runs in subprocess (crash doesn't affect others)
2. **Parallel Execution:** Quick scan runs tools sequentially; Deep scan uses asyncio for parallelism
3. **Standardized Output:** All tools output normalized JSON format
4. **Progress Reporting:** Real-time updates via Redis pub/sub
5. **Graceful Degradation:** If a tool fails, continue with others

6.3 Base Tool Wrapper (tool_wrappers/base.py)
pythonfrom abc import ABC, abstractmethod
from typing import List, Dict, Any, Optional
import subprocess
import json
import logging

logger = logging.getLogger(__name__)

class BaseTool(ABC):
    """
    Base class for all security tool wrappers.
    Each tool inherits from this and implements execute() and parse_output().
    """
    
    def __init__(self, name: str, category: str):
        self.name = name
        self.category = category  # "sast", "dast", "sca", etc.
        
    @abstractmethod
    def execute(self, project_path: str, options: Dict[str, Any]) -> str:
        """
        Execute the tool and return raw output.
        
        Args:
            project_path: Absolute path to project directory
            options: Tool-specific options
            
        Returns:
            Raw output from tool (usually JSON or XML)
            
        Raises:
            ToolExecutionError: If tool fails to run
        """
        pass
    
    @abstractmethod
    def parse_output(self, raw_output: str) -> List[Dict[str, Any]]:
        """
        Parse raw tool output into standardized format.
        
        Args:
            raw_output: Raw output from execute()
            
        Returns:
            List of findings in standardized format:
            [
                {
                    "type": "sql_injection",
                    "severity": "critical",
                    "file_path": "app/Http/Controllers/PaymentController.php",
                    "line_start": 127,
                    "line_end": 127,
                    "message": "Tainted SQL query detected",
                    "confidence": 80,
                    "cwe_id": "CWE-89",
                    "owasp_category": "A03:2021",
                    "tool": "semgrep",
                    "raw": {...}  # Original tool output
                }
            ]
        """
        pass
    
    def run(
        self,
        project_path: str,
        options: Dict[str, Any] = None
    ) -> List[Dict[str, Any]]:
        """
        Run tool and return normalized findings.
        This is the main entry point called by orchestrator.
        """
        options = options or {}
        
        try:
            logger.info(f"Running {self.name} on {project_path}")
            
            # Execute tool
            raw_output = self.execute(project_path, options)
            
            # Parse output
            findings = self.parse_output(raw_output)
            
            # Add metadata
            for finding in findings:
                finding['tool'] = self.name
                finding['category'] = self.category
            
            logger.info(f"{self.name} found {len(findings)} issues")
            return findings
            
        except Exception as e:
            logger.error(f"{self.name} failed: {str(e)}")
            # Don't fail entire scan if one tool fails
            return []
    
    def _run_command(
        self,
        command: List[str],
        cwd: str = None,
        timeout: int = 300
    ) -> str:
        """
        Safely execute shell command using subprocess.
        
        Args:
            command: Command as list (e.g., ["semgrep", "--config", "auto", "/path"])
            cwd: Working directory
            timeout: Max execution time in seconds
            
        Returns:
            stdout from command
            
        Raises:
            subprocess.CalledProcessError: If command fails
            subprocess.TimeoutExpired: If command times out
        """
        result = subprocess.run(
            command,
            cwd=cwd,
            capture_output=True,
            text=True,
            timeout=timeout,
            check=False  # Don't raise on non-zero exit
        )
        
        # Some tools exit with non-zero when findings exist
        # Only raise if stderr indicates actual error
        if result.returncode != 0 and "error" in result.stderr.lower():
            raise subprocess.CalledProcessError(
                result.returncode,
                command,
                output=result.stdout,
                stderr=result.stderr
            )
        
        return result.stdout
6.4 Example Tool Wrapper (tool_wrappers/sast/semgrep.py)
pythonfrom tool_wrappers.base import BaseTool
import json
from typing import List, Dict, Any

class SemgrepTool(BaseTool):
    """Wrapper for Semgrep SAST tool"""
    
    def __init__(self):
        super().__init__(name="semgrep", category="sast")
        
    def execute(self, project_path: str, options: Dict[str, Any]) -> str:
        """
        Run Semgrep with security rules.
        
        Command:
            semgrep --config=auto --json /path/to/project
        """
        # Build command
        command = [
            "semgrep",
            "--config", options.get("config", "auto"),  # auto = community rules
            "--json",
            "--quiet",  # Suppress progress output
            project_path
        ]
        
        # Add exclude paths if provided
        if "exclude_paths" in options:
            for exclude in options["exclude_paths"]:
                command.extend(["--exclude", exclude])
        
        # Execute
        output = self._run_command(command, timeout=600)  # 10 min max
        return output
    
    def parse_output(self, raw_output: str) -> List[Dict[str, Any]]:
        """
        Parse Semgrep JSON output into standardized format.
        
        Semgrep output structure:
        {
          "results": [
            {
              "check_id": "python.lang.security.audit.sqli.sqli",
              "path": "app.py",
              "start": {"line": 10, "col": 5},
              "end": {"line": 10, "col": 50},
              "extra": {
                "message": "SQL injection vulnerability",
                "severity": "ERROR",
                "metadata": {
                  "cwe": "CWE-89",
                  "owasp": "A1:2021"
                }
              }
            }
          ]
        }
        """
        data = json.loads(raw_output)
        findings = []
        
        for result in data.get("results", []):
            # Map Semgrep severity to our standard
            severity_map = {
                "ERROR": "high",
                "WARNING": "medium",
                "INFO": "low"
            }
            semgrep_severity = result["extra"].get("severity", "WARNING")
            severity = severity_map.get(semgrep_severity, "medium")
            
            # Extract vulnerability type from check_id
            check_id = result["check_id"]
            vuln_type = self._extract_type(check_id)
            
            finding = {
                "type": vuln_type,
                "severity": severity,
                "file_path": result["path"],
                "line_start": result["start"]["line"],
                "line_end": result["end"]["line"],
                "message": result["extra"]["message"],
                "confidence": 70,  # Semgrep is fairly accurate
                "cwe_id": result["extra"].get("metadata", {}).get("cwe"),
                "owasp_category": result["extra"].get("metadata", {}).get("owasp"),
                "raw": result
            }
            
            findings.append(finding)
        
        return findings
    
    def _extract_type(self, check_id: str) -> str:
        """
        Extract vulnerability type from Semgrep rule ID.
        Example: python.lang.security.audit.sqli.sqli -> sql_injection
        """
        if "sqli" in check_id.lower():
            return "sql_injection"
        elif "xss" in check_id.lower():
            return "xss"
        elif "command-injection" in check_id.lower():
            return "command_injection"
        elif "path-traversal" in check_id.lower():
            return "path_traversal"
        elif "hardcoded" in check_id.lower():
            return "hardcoded_secret"
        else:
            # Default: use last part of rule ID
            return check_id.split(".")[-1].replace("-", "_")

import logging

logger = logging.getLogger(__name__)

class ScanOrchestrator:
    """
    Orchestrates execution of 50+ security tools.
    Handles tool selection, parallel execution, deduplication.
    """
    
    def __init__(self):
        # Initialize all tool instances
        self.all_tools = {
            # SAST
            "semgrep": SemgrepTool(),
            "codeql": CodeQLTool(),
            "bandit": BanditTool(),
            "phpstan": PHPStanTool(),
            # ... 15 SAST tools total
            
            # Secrets
            "trufflehog": TruffleHogTool(),
            "gitleaks": GitleaksTool(),
            # ... 5 secrets tools total
            
            # SCA
            "trivy": TrivyTool(),
            "grype": GrypeTool(),
            # ... 8 SCA tools total
            
            # Continue for all 50+ tools...
        }
    
    async def run_scan(
        self,
        scan_id: str,
        project_path: str,
        mode: str,  # "quick" or "deep"
        options: Dict[str, Any],
        progress_callback: Callable[[int, str], None] = None
    ) -> Dict[str, Any]:
        """
        Main scan execution function.
        
        Args:
            scan_id: UUID of scan
            project_path: Absolute path to project
            mode: "quick" or "deep"
            options: Additional options (runtime_url, custom_tools, etc.)
            progress_callback: Function to report progress (percentage, message)
            
        Returns:
            {
                "findings": [...],  # List of all findings
                "summary": {...},    # Summary stats
                "tools_executed": [...]  # List of tool names
            }
        """
        project_path = Path(project_path)
        progress = ProgressReporter(scan_id, progress_callback)
        
        # Step 1: Detect project characteristics (5%)
        progress.update(0, "Analyzing project structure...")
        languages = detect_languages(project_path)
        framework = detect_framework(project_path, languages)
        
        logger.info(f"Detected languages: {languages}, framework: {framework}")
        
        # Step 2: Select tools based on mode and project (10%)
        progress.update(5, "Selecting appropriate tools...")
        selected_tools = self._select_tools(mode, languages, framework, project_path, options)
        
        logger.info(f"Selected {len(selected_tools)} tools: {[t.name for t in selected_tools]}")
        
        # Step 3: Execute tools (15% - 90%)
        progress.update(10, "Starting security analysis...")
        
        if mode == "quick":
            # Sequential execution for quick scan (less resource intensive)
            all_findings = await self._run_tools_sequential(
                selected_tools, project_path, options, progress, 15, 90
            )
        else:
            # Parallel execution for deep scan (faster but more resources)
            all_findings = await self._run_tools_parallel(
                selected_tools, project_path, options, progress, 15, 90
            )
        
        # Step 4: Deduplicate findings (90% - 95%)
        progress.update(90, "Deduplicating findings...")
        deduplicated = deduplicate_findings(all_findings)
        
        logger.info(f"Deduplicated {len(all_findings)} -> {len(deduplicated)} findings")
        
        # Step 5: Calculate security score (95% - 100%)
        progress.update(95, "Calculating security score...")
        score = calculate_security_score(deduplicated)
        
        summary = self._generate_summary(deduplicated)
        
        progress.update(100, "Scan completed!")
        
        return {
            "findings": deduplicated,
            "summary": summary,
            "score": score,
            "tools_executed": [t.name for t in selected_tools]
        }
    
    def _select_tools(
        self,
        mode: str,
        languages: List[str],
        framework: str,
        project_path: Path,
        options: Dict[str, Any]
    ) -> List:
        """
        Select appropriate tools based on project characteristics.
        
        Logic:
        - ALWAYS: Secrets scanners (TruffleHog, Gitleaks)
        - IF PHP: Semgrep, PHPStan, Brakeman
        - IF Python: Semgrep, Bandit, Pylint, pip-audit
        - IF JavaScript: Semgrep, ESLint, npm-audit
        - IF Dockerfile present: Hadolint, Dockle, Trivy
        - IF Terraform present: tfsec, Checkov
        - IF mode=deep: Add CodeQL, ZAP (if runtime_url), Nuclei, Infer
        """
        tools = []
        
        # 1. Always include secrets scanners
        tools.extend([
            self.all_tools["trufflehog"],
            self.all_tools["gitleaks"],
        ])
        
        # 2. Language-specific SAST
        if "php" in languages:
            tools.extend([
                self.all_tools["semgrep"],
                self.all_tools["phpstan"],
            ])
        
        if "python" in languages:
            tools.extend([
                self.all_tools["semgrep"],
                self.all_tools["bandit"],
                self.all_tools["pylint"],
            ])
        
        if "javascript" in languages or "typescript" in languages:
            tools.extend([
                self.all_tools["semgrep"],
                self.all_tools["eslint"],
            ])
        
        # 3. SCA (always check dependencies)
        tools.append(self.all_tools["trivy"])
        
        if (project_path / "package.json").exists():
            tools.append(self.all_tools["npm_audit"])
        
        if (project_path / "requirements.txt").exists():
            tools.append(self.all_tools["pip_audit"])
        
        # 4. Container security
        if (project_path / "Dockerfile").exists():
            tools.extend([
                self.all_tools["hadolint"],
                self.all_tools["dockle"],
            ])
        
        # 5. IaC security
        if list(project_path.glob("**/*.tf")):  # Terraform files
            tools.extend([
                self.all_tools["tfsec"],
                self.all_tools["checkov"],
            ])
        
        # 6. Deep scan additions
        if mode == "deep":
            tools.extend([
                self.all_tools["codeql"],  # Expensive but thorough
                self.all_tools["infer"],   # Advanced static analysis
            ])
            
            # DAST if runtime URL provided
            if options.get("runtime_url"):
                tools.extend([
                    self.all_tools["zap"],
                    self.all_tools["nuclei"],
                ])
        
        # 7. Custom tool selection (if user specified)
        if "custom_tools" in options:
            custom = [self.all_tools[name] for name in options["custom_tools"]]
            tools = custom
        
        # Remove duplicates (preserve order)
        seen = set()
        unique_tools = []
        for tool in tools:
            if tool.name not in seen:
                seen.add(tool.name)
                unique_tools.append(tool)
        
        return unique_tools
    
    async def _run_tools_sequential(
        self,
        tools: List,
        project_path: Path,
        options: Dict[str, Any],
        progress: ProgressReporter,
        start_pct: int,
        end_pct: int
    ) -> List[Dict[str, Any]]:
        """Run tools one by one (for Quick scan)"""
        all_findings = []
        total_tools = len(tools)
        pct_per_tool = (end_pct - start_pct) / total_tools
        
        for i, tool in enumerate(tools):
            current_pct = start_pct + int(i * pct_per_tool)
            progress.update(current_pct, f"Running {tool.name}...")
            
            findings = tool.run(str(project_path), options)
            all_findings.extend(findings)
            
            progress.update(current_pct + int(pct_per_tool), f"{tool.name} completed - {len(findings)} findings")
        
        return all_findings
    
    async def _run_tools_parallel(
        self,
        tools: List,
        project_path: Path,
        options: Dict[str, Any],
        progress: ProgressReporter,
        start_pct: int,
        end_pct: int
    ) -> List[Dict[str, Any]]:
        """Run tools in parallel (for Deep scan)"""
        tasks = []
        for tool in tools:
            # Wrap sync tool.run() in async executor
            task = asyncio.create_task(
                asyncio.to_thread(tool.run, str(project_path), options)
            )
            tasks.append((tool.name, task))
        
        all_findings = []
        completed = 0
        total = len(tasks)
        
        for tool_name, task in tasks:
            progress.update(
                start_pct + int((completed / total) * (end_pct - start_pct)),
                f"Running {tool_name}..."
            )
            
            findings = await task
            all_findings.extend(findings)
            completed += 1
            
            progress.update(
                start_pct + int((completed / total) * (end_pct - start_pct)),
                f"{tool_name} completed - {len(findings)} findings"
            )
        
        return all_findings
    
    def _generate_summary(self, findings: List[Dict[str, Any]]) -> Dict[str, int]:
        """Generate summary statistics"""
        summary = {
            "critical": 0,
            "high": 0,
            "medium": 0,
            "low": 0,
            "info": 0
        }
        
        for finding in findings:
            severity = finding.get("severity", "info")
            summary[severity] = summary.get(severity, 0) + 1
        
        return summary

6.6 Deduplication Engine (utils/deduplication.py)
pythonfrom typing import List, Dict, Any
from collections import defaultdict
import difflib

def deduplicate_findings(findings: List[Dict[str, Any]]) -> List[Dict[str, Any]]:
    """
    Deduplicate findings from multiple tools.
    
    Strategy:
    1. Exact match: Same file + line number
    2. Fuzzy match: Same file + within 5 lines + same vuln type
    3. Merge matching findings, increase confidence
    
    Returns:
        Deduplicated list with merged findings
    """
    # Group by file_path for efficiency
    by_file = defaultdict(list)
    for finding in findings:
        by_file[finding["file_path"]].append(finding)
    
    deduplicated = []
    
    for file_path, file_findings in by_file.items():
        # Sort by line_start for easier matching
        file_findings.sort(key=lambda f: f["line_start"])
        
        merged = []
        skip_indices = set()
        
        for i, finding in enumerate(file_findings):
            if i in skip_indices:
                continue
            
            # Look for duplicates
            duplicates = [finding]
            
            for j, other in enumerate(file_findings[i+1:], start=i+1):
                if j in skip_indices:
                    continue
                
                if _is_duplicate(finding, other):
                    duplicates.append(other)
                    skip_indices.add(j)
            
            # Merge duplicates
            merged_finding = _merge_findings(duplicates)
            merged.append(merged_finding)
        
        deduplicated.extend(merged)
    
    return deduplicated

def _is_duplicate(f1: Dict[str, Any], f2: Dict[str, Any]) -> bool:
    """
    Check if two findings are duplicates.
    
    Criteria:
    - Same file_path (already grouped)
    - Line numbers within 5 lines
    - Same vulnerability type OR high code similarity
    """
    # Check line proximity
    line_diff = abs(f1["line_start"] - f2["line_start"])
    if line_diff > 5:
        return False
    
    # Exact line match
    if f1["line_start"] == f2["line_start"]:
        return True
    
    # Same vuln type + close lines
    if f1["type"] == f2["type"] and line_diff <= 2:
        return True
    
    # Code snippet similarity (if available)
    if f1.get("code_snippet") and f2.get("code_snippet"):
        similarity = difflib.SequenceMatcher(
            None,
            f1["code_snippet"],
            f2["code_snippet"]
        ).ratio()
        
        if similarity > 0.8 and line_diff <= 5:
            return True
    
    return False

def _merge_findings(findings: List[Dict[str, Any]]) -> Dict[str, Any]:
    """
    Merge multiple findings into one.
    
    Strategy:
    - Keep first finding as base
    - Aggregate tools that detected it
    - Increase confidence based on # of confirmations
    - Keep highest severity
    - Aggregate raw outputs
    """
    base = findings[0].copy()
    
    # Aggregate detecting tools
    all_tools = []
    for f in findings:
        all_tools.append(f["tool"])
    base["detected_by_tools"] = list(set(all_tools))
    
    # Calculate confidence score
    # Formula: base_confidence + (10 * additional_confirmations)
    # Capped at 100
    base["confidence"] = min(
        100,
        base["confidence"] + (10 * (len(findings) - 1))
    )
    
    # Keep highest severity
    severity_order = ["critical", "high", "medium", "low", "info"]
    severities = [f["severity"] for f in findings]
    base["severity"] = min(severities, key=lambda s: severity_order.index(s))
    
    # Aggregate raw outputs
    base["raw_outputs"] = {f["tool"]: f.get("raw", {}) for f in findings}
    
    # Prefer longer messages (more detail)
    longest_message = max(findings, key=lambda f: len(f.get("message", "")))
    base["message"] = longest_message["message"]
    
    return base
6.7 Security Score Calculation (utils/scoring.py)
pythonfrom typing import List, Dict, Any

def calculate_security_score(findings: List[Dict[str, Any]]) -> float:
    """
    Calculate security score from 0.0 to 10.0.
    
    Formula:
    - Start at 10.0 (perfect)
    - Deduct points based on severity:
      * Critical: -2.0 per finding
      * High: -1.0 per finding
      * Medium: -0.3 per finding
      * Low: -0.1 per finding
      * Info: -0.05 per finding
    - Weight by confidence (low confidence = less penalty)
    - Floor at 0.0
    
    Examples:
    - 1 critical: 10.0 - 2.0 = 8.0
    - 3 critical, 8 high: 10.0 - 6.0 - 8.0 = -4.0 -> 0.0 (floor)
    - 15 medium: 10.0 - 4.5 = 5.5
    """
    score = 10.0
    
    severity_weights = {
        "critical": 2.0,
        "high": 1.0,
        "medium": 0.3,
        "low": 0.1,
        "info": 0.05
    }
    
    for finding in findings:
        severity = finding.get("severity", "info")
        confidence = finding.get("confidence", 100) / 100.0  # Normalize to 0-1
        
        # Penalty = weight * confidence
        # (Low confidence findings penalized less)
        penalty = severity_weights[severity] * confidence
        score -= penalty
    
    # Floor at 0.0, ceiling at 10.0
    return max(0.0, min(10.0, round(score, 1)))
